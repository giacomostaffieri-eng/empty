# Knowledge Base — Tech Resolver

Conoscenza pratica verificata da Account Manager / Solutions Engineer, usata dal comando `/tech-resolver`
come **fonte prioritaria** (prima di Confluence).

Aggiungi un file `.md` per tema (es. `decline-codes.md`, `market-france.md`, `underwriting-gotchas.md`,
`acceptance-playbook.md`). Vedi il formato in `../tech-resolver-AM-intake.md`.

Regola d'oro: ogni voce ha **Fonte** e **Confidenza**. Se una voce è a bassa confidenza, il resolver non la
usa per una mail al cliente ma propone di coinvolgere un SE.
